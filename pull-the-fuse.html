// Echo Event 02 — Puzzle Solving

Pull the Fuse

Two coordinate dice — Red and Blue. Cut all six fuses using each die's face, their sum, or their difference before you run out of rolls.

Wager: Stake one resource before rolling. No resource = automatic failure.
Win: All 6 fuses cut within 3 rolls — wager returned, doubled.
System Surge: Rolling doubles cuts the matching fuse, plus lets you pick one more open fuse to shut.
Fail: Rolls exhausted with fuses still open — wager lost, +1 Noise per open fuse.
