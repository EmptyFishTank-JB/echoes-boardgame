ECHO DEV TOOLS v.—

// local editors for the terminal's content JSON — read live from GitHub, edits export as a download
TOOLS
LORE // DEV LOG EDITOR v.—
Edits terminal-data/lore.json and dev_logs.json — the terminal's discoverable lore entries and developer log content.
NODE GRAPH EDITOR v.—
Edits terminal-data/nodes.json — the terminal's layer/node navigation tree, laid out as a visual graph.
PERSONALITY LAB v.—
Edits terminal-data/personality.json — easter eggs, denied responses, admin triggers, self-destruct sequence.
TERMINAL ENGINE EDITOR v.—
Edits terminal-data/engine_config.json — idle messages, typing/audio timing, theme, boot behavior.
BOARD EDITOR v.—
Edits board-data/board.json — a grid-based, printable board layout: rooms with family tags, walls/doors, terminals, vents, and lockers. For physical playtesting, not the terminal.
RULES EDITOR v.—
Open a local copy of rules.html (or another page) to edit it with the same in-page components used on the live site. Nothing is embedded in the real page — edits export as a download.
ARTIFACTS // reference & prototypes, not editors
TERMINAL AUDIO COMPENDIUM v.—
Every synthesized sound effect from the archived and live terminals, playable side by side. Growing — new effects get added here as they're built.
GAME UI MOCKUP v.—
A digital-adaptation concept for the play screen — noise tracker, board viewport, crew/creature intel, task board, and the full player HUD. Opened from here, it live-fetches board-data/board.json instead of falling back to its baked-in snapshot.
RULES PAGE — FX DEMO v.—
A full copy of rules.html with film grain and a chromatic-aberration glitch burst layered on top, tested against real dense page content instead of a blank page. Bottom-right controls: trigger a glitch on demand, toggle grain, toggle auto-glitch, and set its random interval.
Background Comparison — Home The real home page with a top-right toggle to preview it against the other pages' background treatments — flat dark, the mini-games' gradient glow, or pure black. Background Comparison — Rules Same toggle, on a full copy of rules.html — for comparing background treatments against dense real content. Background Comparison — Pull the Fuse Same toggle, on a full copy of a mini-game page — this one already uses the "gradient glow" treatment by default, unlike home/rules. Dice Style Comparison Four candidate looks for the Red/Blue coordinate dice — flat gradient, translucent glass, CSS marble, SVG turbulence swirl. Table View Toggle Per-table [|||]/[≡] button to switch between the normal column table and a stacked dictionary-entry view, plus the same auto-switch below 640px. Tested against the Dice Engine and Combat weapon-pool tables from rules.html. SFX Test Rig A/B candidates for Cascade Failure's threshold chime and bust alert, plus every sound currently live in the mini-games and unused terminal sounds. Favicon Workshop Drag-and-drop editor for building tool favicons — move, scale, rotate, recolor, and freehand-draw layers, then export as SVG, a data URI, or a drop-in animated JS snippet. Built the Board Editor's favicon. Loading Bar Demo Alien Isolation-style loading bar concept — hollow white rectangle that fills solid left to right, orange Share Tech Mono "LOADING..." label. Replay button and speed selector to tweak the feel before it goes anywhere real.
