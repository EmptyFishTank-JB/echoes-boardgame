01 One-Shot Effects

Ten short, procedurally-generated sounds — clicks, tones, and noise bursts built from oscillators and filtered noise buffers, fired in response to typing, input, and story beats. Every one of these is byte-for-byte identical code in both files; what differs is where in the UI each gets called.

02 Ambient Beds

The background drone that plays continuously once the terminal powers on. This is the one part of the audio system that's genuinely different between the two builds — press play to compare a constant single-oscillator hum against the live engine's three crossfading layers.

03 What Changed

// SIGNAL COMPARISON — ARCHIVE vs LIVE

  • =All 10 one-shot effects carried over unchanged. Click, punctuation click, enter, backspace, alert, denied burst, line static, think hum, egg tone, and idle pop all use identical synthesis parameters in both files — nothing was lost in the v42 promotion.
  • +Denied, static, and egg-tone sounds got wired into far more places. The archive only calls playDenied() and playEggTone() from a single input handler; the live engine reuses them across fetch errors, layer transitions, self-destruct, and lore discovery — same sound, broader vocabulary.
  • +Idle pop's trigger changed from a blind timer to a config-driven system. Archive: a fixed 15-second inactivity timer pops in silence. Live: delay and message pool are configurable via engine_config.json, and the pop always accompanies a visible idle message.
  • +Ambient is the real rebuild. Archive plays one constant 42 Hz drone at fixed volume from power-on to close. Live crossfades between three distinct oscillator stacks — one per layer — each independently tunable from the new Terminal Engine Editor dev tool.
