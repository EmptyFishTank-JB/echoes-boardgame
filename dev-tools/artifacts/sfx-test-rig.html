SFX Test Rig

Everything here is synthesized live with the Web Audio API — no sample files, same approach as the sounds already wired into the mini-games. Section 1 is the main event: seven candidate replacements for Cascade Failure's 14 / 18 / 21 threshold chime, each played at the same three pitches so they're easy to A/B. The rest is for browsing — sounds from terminal.html that never made it into a game, and the sounds already live today, side by side for reference.

01 Threshold Chime Candidates

Each card is one synthesis approach. "Low / Mid / High" map to hitting 14, 18, and 21. "Play All" runs them in sequence so you can hear the rise.

02 Bust / Overload Alert Candidates
