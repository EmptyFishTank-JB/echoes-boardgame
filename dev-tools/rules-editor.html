// Standalone Rules Editor

Open a local HTML copy of a site page (for example rules.html) to explore and use the same in-page editing components and options available on the live site, without the editor being embedded in the real file. Nothing is uploaded — the file is read and edited entirely in this browser tab. When finished, use Save / Save As in the editor toolbar to write the edited copy back out, then hand that file over to have the matching changes applied to the actual page in the repo.

Chrome / Edge recommended — enables direct Save back to the same file on disk.
