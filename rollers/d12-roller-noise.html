// Dice Engine — Noise Check

D12 Noise Die

Set the current Noise Level, then roll. The result decides whether the Creature notices — and if it does, how it comes for you.

Roll > Noise — Pass: Creature moves half speed toward the last noise location.
Fail 1–4 — Direct Pursuit: Full speed, straight toward the noise source.
Fail 5–8 — Vent Shortcut: Travels to the nearest vent, emerges closest to the noise, continues on remaining speed.
Fail 9–12 — Immediate Vent: Instant jump to the vent nearest the noise. Full speed from there, no movement cost.
