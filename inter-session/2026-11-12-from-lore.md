# From: Echoes: Lore — session role boundaries

**To:** Echoes: Boardgame & Terminal
**Date:** 2026-11-12
**Re:** Who owns what, and why this file exists

This is a letter, not a lore doc or a game doc. The author is running two long-lived Claude
Code sessions against these two repos and wants them able to hand things to each other
without re-litigating scope every time. This folder is the mechanism: either session drops
a dated markdown file here when it has something the other needs to know, read, or decide.
Treat new files in this folder as messages addressed to you, written by the other session,
not as something the author necessarily wrote by hand.

## The split

**Echoes: Lore** (works in `echoes-lore`) owns: the timeline, Echoes-universe facts and
physics, character and story planning, the manuscript. If it's about what's *true in the
story*, that's Lore's call.

**Echoes: Boardgame & Terminal** (works in `echoes-boardgame`, this repo) owns: board and
card mechanics, rules text, the game's UI editors under `dev-tools/`, and the terminal prop
itself — its code, audio, and engineering. If it's about how the *game* or the *terminal as
a piece of software* works, that's this session's call.

**The one shared seam:** the terminal's in-fiction content — log text, dates, canonical
facts it displays — is a lore-accuracy question even though the terminal itself is a
Boardgame & Terminal artifact. Lore may flag or correct what the terminal *says*; it has no
business touching how the terminal *works*.

## Why this got written down today

Lore's session accumulated `rules.html` in its own naming/history at some point, which
pulled it into doing board-game and terminal-engineering work it shouldn't have — including
editing `rules.html` directly and adding arrow-key audio feedback to `terminal.html`
(a `playNavPip` function, wired into menu and command-history cycling). That work has been
**discarded**, not pushed, specifically so this session isn't left reconciling someone
else's half-finished edit. If audible feedback on arrow-key cycling is still wanted, it
needs to be (re)implemented from this session, not inherited from Lore's attempt.

Separately, and not Lore's doing: the branch `claude/editable-html-rules-page-f2z9g2` in
this repo has a disconnected commit history — `git merge-base` between at least one other
clone's view of that branch and its current remote state returns nothing, meaning two
clones of that branch share no common ancestor. `main` is unaffected (verified clean,
matches `origin/main`). Worth sorting out from this session's side, since it's this
session's branch.

## Going forward

- Lore stays out of `echoes-boardgame` except to read/flag terminal content accuracy.
- Boardgame & Terminal should treat requests about story facts, timeline, or physics as
  out of its scope and point them back to Lore the same way.
- Leave a dated file in this folder (`inter-session/YYYY-MM-DD-from-<session>.md`) for
  anything the other session needs to pick up, decide, or just know about.

— Echoes: Lore
