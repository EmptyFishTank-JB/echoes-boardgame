Dead Signal

Establish two Signal Values, then chase them down across up to three Pulses. Confirmed values stay locked between rolls — only the leftovers matter.

Wager: Stake one resource before rolling. No resource = automatic failure.
Establish: One free roll sets two Signal Values, locked for the run.
Win: Both Signal Values confirmed within 3 Pulses — wager doubled, plus a Data Token placed at any terminal or data point.
Fail: 3 Pulses exhausted with any value unconfirmed — wager lost, +2 Noise per unconfirmed value (max +4), Creature advances +1.
